ε-Horn Torus Observer

A path winds around the torus with winding ratio ω. An observer inside it takes frames and remembers the first one. It registers a count each time a frame comes back into the δ-neighborhood of that memory, counting only on re-entry. Each poloidal pass through the portal counts only if it lands in one of the k open windows, and their width is set by ε.

Diagnostics

Modeling choices in this viewer

  • Geometry. R = 1 and r = 1 − ε, so ε is the hole radius.
  • Flow. Between passes the path is a straight line on the flat torus with velocity (1, ω). A pass is the poloidal angle crossing φ = ½, the inner equator, which at ε = 0 is the single horn point.
  • Gate. There are k windows at θ = j/k, each of width w = cw|ε|. A blocked pass still goes through. It just doesn't add to the portal count. At ε = 0 only exact hits count.
  • Locking. At each pass, θ ← θ − (K/2πk)·sin(2πkθ) with K = cK|ε|. That turns the pass map into a k-fold circle map.
  • Eversion flip (ε < 0 only, experimental). Either the pull reverses sign at each pass, or θ is mirrored to −θ at each pass.
  • Truth. The exact flow is sampled at 12–24× the frame rate. A true return is an entry into the flat δ-disk around the actual start in both angles. So the observer can be wrong in two ways: by missing returns, or by counting false ones when its projection or memory differs from the true state.
